Component spec files live here as `*.spec.md` and are required before dispatching any builder agents.

Spec template:
- See `.codex/skills/clone-website/SKILL.md` for the required spec template and fields.

Create one file per component, e.g.:
- `Hero.spec.md`
- `Nav.spec.md`
- `FeatureCard.spec.md`

Each spec must include computed styles from `getComputedStyle()` and explicit interaction model documentation.
